# Acorn Finance

> Acorn Finance, operated by Headway Sales Inc. (NMLS ID# 1817022) of Sacramento, California, runs an embedded lending marketplace for home improvement and business financing. Consumers pre-qualify for personal loans of $1,000 to $100,000 with a soft credit pull and compare offers from a network of lending partners; contractors, dealers and point-of-sale software vendors embed those offers into estimates, invoices, quotes, carts and PDFs.

This file was generated by API Evangelist from Acorn Finance's own public documentation on 2026-09-06. Acorn Finance does not publish an llms.txt of its own (/llms.txt returns 404 on www.acornfinance.com and docs.acornfinance.com).

## What is and is not machine-readable

Acorn Finance publishes detailed, public, human-readable partner documentation at https://docs.acornfinance.com/ — a client-rendered single-page app, freely accessible with no login. It publishes NO machine-readable API contract: no OpenAPI, no Swagger, no GraphQL schema, no AsyncAPI, no WSDL, no Protobuf, no Postman collection, no /.well-known/ document, no MCP server and no A2A agent card. All of those paths were probed on 2026-09-06 against api.acornfinance.com, uat.api.acornfinance.com, docs.acornfinance.com, my.acornfinance.com, sign-up.acornfinance.com and www.acornfinance.com, and every one missed.

Note also that https://developer.acornfinance.com/ is a Stoplight-hosted portal carrying Acorn Finance branding in its page head but serving the API catalogue of an unrelated company (Autopay.io) in its body. It is not Acorn Finance's documentation. Use docs.acornfinance.com.

## API

- [Developer documentation](https://docs.acornfinance.com/overview): Partner developer docs — widgets, API, and integration guides.
- [API authorization and onboarding](https://docs.acornfinance.com/api-sign-up): HTTP Basic auth. Credentials are issued per partner after company sign-up plus an email to it@acornfinance.com; stated turnaround is 48 hours Mon-Fri. Credentials rotate every 90 days.
- [Active credentials](https://docs.acornfinance.com/api-active-credential): GET https://api.acornfinance.com/active_credentials — returns the current username, password, created_at and expires_on.
- [Applications API](https://docs.acornfinance.com/api-applications): GET https://api.acornfinance.com/company_applications — list loan applications by application id (aid), company id (cid), dealer id (did), applicant email/name, status, or date range; paged with page/per_page (10/20/50/100) and a `latest` shortcut (20/50/100/200). Labelled IN BETA. Statuses: NO OFFER, OFFERED, SELECTED, FUNDED, EXPIRED.
- [Company API](https://docs.acornfinance.com/api-company): POST https://api.acornfinance.com/app_companies — create a contractor company and its first admin user. Supports parent/child company hierarchies.
- [Company User API](https://docs.acornfinance.com/api-company-user): POST https://api.acornfinance.com/company_users — create an additional user for an existing company.
- [Lowest Payment Amount API](https://docs.acornfinance.com/api-lowestpaymentamount): POST https://api.acornfinance.com/lowest-payment-amount — lowest monthly payment for a loan amount between $1,000 and $100,000.
- [Lowest Payment Amount Link API](https://docs.acornfinance.com/api-lowestpaymentamountlink): POST https://api.acornfinance.com/lowest-payment-amount-link — payment quote plus a hosted loan application URL and location-aware CTA copy. US and Canada contracts differ; supported ranges vary by state (GA $3,001+, TX $2,000+, MA $6,700+, other supported states $1,000+; Canada $2,000-$35,000 CAD, QC and SK unsupported).
- [Partner Postback API](https://docs.acornfinance.com/api-postback): Acorn POSTs application status changes (OFFERED, NO OFFER, FUNDED) to a partner-hosted HTTPS URL with the partner's key in an X-Authorization header, and uses the partner's reply to compose borrower emails.

Testing environment: every endpoint above is mirrored at https://uat.api.acornfinance.com with separately issued credentials.

- [Payment Estimator](https://docs.acornfinance.com/payment-estimator): the `af-payment-estimator` component, or the hosted iframe at https://widgets-cdn.acornfinance.com/payment-estimator/payment-estimator.html.
- [Lenders List Widget](https://docs.acornfinance.com/lenders-list): hosted iframe at https://fs.acornfinance.com/widget/lenlst/index.html.
- [Momnt Widget](https://docs.acornfinance.com/momnt-widget): lending-partner widget bundle.
- [Shopify theme](https://docs.acornfinance.com/shopify) and [Shopify checkout](https://docs.acornfinance.com/shopify-checkout): drop-in storefront scripts.
- [Loan platform link parameters](https://docs.acornfinance.com/loan-platform-parameters) and [payment link generator](https://docs.acornfinance.com/loan-payment-link-generator): parameterised links into the hosted application flow.
